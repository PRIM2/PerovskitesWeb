Interactive plotting


Select grouping: use the Group by menu to organize data points by cation or anion.

Control datasets: upload new datasets or remove existing ones with the provided buttons. You can hide or display groups of points as needed.

Adjust the axes: define minimum and maximum values for both axes to zoom into specific regions of interest. Apply or reset the scale at any time.

Add custom points: enter a name, globularity (X), tolerance factor (Y), and choose visual properties such as color, size, and shape.

Manage custom data: edit or delete previously added custom points directly in the table. Use Clean manual points to remove all at once.

Export results: download the graph as a .png image or export the custom points as a .csv file for further analysis.
