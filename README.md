# 🧪 HyPer TolKit – Perovskites Web

**HyPer TolKit** is an interactive web application for the **analysis of perovskite materials** based on geometric and structural parameters.  
The platform allows users to **calculate**, **explore**, **visualize**, and **query** perovskite-related data directly from the browser.

🌐 **Online web**  
👉 https://prim2.github.io/HyperToolkit/

---

## 🔬 What can this web do?

The application is organized into **four main tools**:

### 1️⃣ Tolerance Factor
Interactive calculation of the **extended tolerance factor** using:
- A-site cation
- B-site cation
- Anion

Features:
- Mathematical formula rendered in LaTeX  
- Explicit control of ionic radii and geometric parameters  
- Numerical result of the tolerance factor  

---

### 2️⃣ Ion Range Finder
Tool designed to explore **stability ranges** as a function of:
- Ionic radii
- Characteristic bond lengths
- Possible A–B–X combinations

Intended for **fast screening of viable compositions**.

---

### 3️⃣ Data Visualization
Graphical visualization of structural data through:
- Interactive plots
- Tolerance factor correlations with other parameters
- Visual exploration of trends in known perovskite materials

---

### 4️⃣ Data Base Query
Direct query interface for a **perovskite database** including:
- Bibliographic information
- SMILES strings for cations and anions
- Geometric parameters
- Spin states and tolerance factors
